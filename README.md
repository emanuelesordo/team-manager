# Team Manager

Nuova app mobile-first per la gestione della squadra.

## Stack
- HTML/CSS/JavaScript modulare
- Supabase Auth + PostgreSQL + Realtime
- GitHub Pages

## Moduli
- Home squadra
- Calendario partite
- Livescore collaborativo
- Statistiche
- Profilo/Login
- Amministrazione desktop

Backend: progetto Supabase `team-manager`.
